邓丽君是20世纪华语流行音乐极具代表性的人物。于1967年推出首张个人专辑《凤阳花鼓》，从而开始她的歌唱生涯。

她的音乐语种主要涉及闽南话、粤语、国语、粤语、英语等。

她是全球华人地区流行文化的代表人物之一，在全世界范围内有着巨大的影响力。



## About this

2026年，对话式AI已经融入了人们的日常生活。使用AI提升效率是一件非常常见的事情。

邓丽君的歌曲曲目涉猎非常广，目前我还没有接触到令我满意的整理方案。

于是，此项目就诞生了。



## The albums usually contain old songs.

专辑除了新曲目，大概率包含旧曲目。这里猜测原因：

- 早期专辑通常是以光盘的形式发行。听众想要听音乐，需要花钱购买。
- 专辑通常以12、16首等这些常见的曲目数量进行包装。
- 新曲目意味着不确定性，不清楚听众的感觉，加入旧曲目能提升听众的心理接受程度。



处理思路：

- 在本项目中，保留曲目在专辑中的序号信息。如果是旧曲目，则在当前专辑中，移除该曲目。
