# Alien Shooter

Alien Shooter系列游戏源于 [Sigma Team](https://www.sigma-team.com/)。

目前活跃在互联网的主流版本有：[Alien Shooter](https://www.sigma-team.com/alien-shooter)、[Alien Shooter 2 – Reloaded](https://www.sigma-team.com/alien-shooter-2-reloaded)。

- 其中，Alien Shooter有两个扩展版本：[Fight for Life](https://www.sigma-team.com/alien-shooter-fight-for-life)、[The Experiment](https://www.sigma-team.com/alien-shooter-the-experiment)。
